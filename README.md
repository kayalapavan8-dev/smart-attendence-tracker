
# 📱 Smart Attendance Tracker

Smart Attendance Tracker is a Flutter-based application designed to simplify student attendance management. It helps users track attendance records, view attendance summaries, and manage attendance information through a simple and user-friendly interface.

---

## ✨ Features

- 🔐 **Firebase Authentication:** User login and authentication.
- 📊 **Attendance Dashboard:** View attendance counts and summaries.
- 🧑‍🎓 **Student Attendance Management:** Maintain student attendance records.
- 📚 **Subject-Wise Attendance:** Track attendance for individual subjects.
- 📈 **Attendance History:** View previously recorded attendance details.
- ☁️ **Firebase Integration:** Connect the application with Firebase services.
- 🎨 **Clean UI:** Simple, modern, and user-friendly interface.

---

## 🛠️ Tech Stack & Tools

- **Framework:** [Flutter](https://flutter.dev/)

## 🚀 How to Run the App Locally

### Prerequisites

- Ensure you have the [Flutter SDK](https://docs.flutter.dev/get-started/install) installed.
- Ensure Android Studio or VS Code is installed.
- Ensure an Android emulator or physical device is connected.
- Configure your own Firebase project for the application.

### Steps

1. **Clone the repository:**

   ```bash
   git clone https://github.com/BhavyaPasupuleti77/smart-attendance-tracker.git
   ```

2. **Open the project folder:**

   ```bash
   cd smart-attendance-tracker
   ```

3. **Install dependencies:**

   ```bash
   flutter pub get
   ```

4. **Configure Firebase:**

   Set up a Firebase project and configure the application with your Firebase settings.

5. **Run the application:**

   ```bash
   flutter run
   ```
